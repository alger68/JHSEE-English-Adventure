# 🎮 JHSEE English Adventure

國三教育會考英文每日 10 分鐘闖關學習系統。

## 目標
- 每天 8–12 分鐘英文閱讀
- 會考核心字彙、片語與閱讀理解
- 透過 EXP、Level、Streak 與 Boss Challenge 建立持續學習習慣
- 逐步由 B++ → A → A+ → A++

## 每日任務
1. 📖 120–180 字短文
2. 🔑 5 個核心單字
3. 🧩 1–2 個片語
4. 🎯 3 題會考型選擇題
5. 🔍 1 個上下文推論任務
6. ⭐ EXP / Streak

## 每週主題
- Mon — 校園故事
- Tue — 日常生活
- Wed — 對話 / 訊息
- Thu — 科普閱讀
- Fri — 公告 / 圖表 / 廣告
- Sat — Boss Challenge
- Sun — 單字與錯題復活賽
